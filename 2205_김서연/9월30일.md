#### <일주일 동안 겪었던 힘든 점, 극복했다면 해결 방법>
1. Router, Service, Repository 등이 각각 서로 어떻게 연결되는지 이해하는 게 어려웠다. 기존 코드를 참고하면서 각 파일의 역할을 하나씩 확인하고, 직접 코드를 작성하고 수정해보면서 API의 전체적인 구조를 이해하려고 했다. 
2. 코드 리뷰에서 받은 질문에 답하기 위해 다른 친구가 작성한 코드를 확인하는 과정에서 내가 직접 작성한 코드가 아니라서 왜 그렇게 작성했는지 이해하기 어려웠고, 잘못된 부분들을 수정하는 것도 어려웠다. 질문받은 부분을 직접 실행해보거나 찾아보면서 이해하려고 했다.

#### <내가 잘한 것과 더 잘할 수 있었는데 아쉬웠던 점>
맡은 부분은 직접 코드를 작성하고 API까지 구현하면서 이전보다 빨리 이해하게 된 점이 이전보다 좋아졌다고 생각한다. 하지만 직접 작성한 코드만 알고 프로젝트의 전체적인 코드 흐름이나 어떻게 연결되는지는 잘 파악하지 못해서 코드 리뷰를 하면서 모르는 부분이 있어서 질문에 답하거나 수정할 때 시간이 오래 걸렸다. 처음부터 전체적인 흐름을 같이 파악했으면 더 빠르게 대답하고 수정할 수 있었을 것 같다.
