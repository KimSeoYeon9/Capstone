## 일주일 동안 내가 만들어 낸 것

이번 주에는 캡스톤 프로젝트의 전체적인 디자인을 마무리하고, 디자인한 내용을 실제 웹 페이지로 구현하는 작업을 진행했다.

먼저 기존에 작업했던 디자인을 과장님에게 피드백 받으며 수정하였다. 특히 작업자가 화면을 봤을 때 필요한 정보를 빠르게 확인할 수 있도록 화면 구성을 정리하고, NG가 발생했을 때 눈에 잘 들어올 수 있도록 관련 부분을 강조해서 수정했다.

디자인을 마무리한 후에는 프론트엔드 구현을 시작했다. 먼저 로그인 페이지를 구현했으며, 디자인에 맞춰 입력창과 로그인 버튼 등의 UI를 구성했다. 실제 코드로 화면을 구현하면서 디자인에서 보던 모습과 실제 웹 페이지에서 보이는 모습이 조금씩 다를 수 있다는 것을 알게 되었다

## 일주일 동안 겪었던 힘든 점, 극복했다면 해결 방법

이번 주에는 피그마를 거의 처음 사용해보는 것이어서 디자인 작업을 하는 과정이 어려웠다. 기본적인 기능은 사용할 수 있었지만 막상 직접 화면을 디자인하려고 하니 어떤 식으로 구성해야 할지 아이디어가 잘 떠오르지 않았다. 특히 프로젝트의 특성에 맞으면서도 사용하기 편한 화면을 만드는 것이 생각보다 어려웠다.

이를 해결하기 위해 다른 웹사이트나 비슷한 형태의 화면들을 참고하면서 어떤 방식으로 정보를 배치하면 좋을지 찾아보았다. 참고한 디자인을 그대로 따라 하기보다는 프로젝트에 필요한 기능과 화면 구성에 맞게 조금씩 수정하면서 디자인을 완성해 나갔다. 피그마를 사용하면서 모르는 기능은 직접 찾아보고 여러 번 수정해보면서 사용법도 익힐 수 있었다.

## 내가 잘한 것과 더 잘할 수 있었는데 아쉬웠던 점

이번 주에는 맡은 디자인 작업을 끝까지 마무리하고 실제 페이지 구현까지 이어서 진행한 점이 잘한 부분이라고 생각한다. 디자인만 완성하는 것이 아니라 직접 코드를 작성해서 웹 페이지로 구현해보면서 프론트엔드 개발에 대한 경험도 쌓을 수 있었다.

아쉬웠던 점은 디자인을 수정하는 과정에서 세부적인 부분을 계속 수정하다 보니 생각보다 시간이 오래 걸렸다는 것이다. 처음 디자인을 할 때 실제 구현하는 과정까지 조금 더 생각하고 작업했다면 구현할 때 수정하는 시간을 줄일 수 있었을 것 같다.

## 다음주까지 해올 것

다음 주에는 로그인 페이지를 조금 더 보완하고, 프로젝트에서 필요한 다른 화면들도 순차적으로 구현할 예정이다. 또한 백엔드에서 데이터를 받아 화면에 보여줄 수 있도록 API 연동 부분을 확인하고, 프론트엔드와 백엔드가 정상적으로 연결될 수 있도록 작업할 예정이다.
